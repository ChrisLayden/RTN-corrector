# RTN-corrector

Code for removing random telegraph noise (RTN) from astronomical images taken with CMOS sensors.

## Overview

RTN manifests as discrete, random jumps in pixel signal levels due to individual charge traps in solid-state image sensors. This package provides two scripts:

1. **`rtn_fitter.py`** — Identifies RTN-affected pixels from a stack of bias frames and fits their noise parameters as a sum of three Gaussians.
2. **`rtn_fixer.py`** — Applies RTN correction to science frames using the fitted parameters, detecting and correcting RTN jumps on a per-frame basis.

Both scripts rely on a precomputed threshold lookup table (`rts_threshold_lut.pkl`), generated by `scripts/make_lut.py`.

## Usage

### Step 1: Fit RTN Parameters (`rtn_fitter.py`)

Identifies RTN pixels from a stack of bias frames (at least 1000 recommended, 5000 is ideal) and fits their parameters.

```
python rtn_fitter.py <bias_folder> <gain> [options]
```

**Arguments:**

| Argument | Description |
|---|---|
| `bias_folder` | Path to folder containing bias FITS files |
| `gain` | Sensor gain in ADU/e⁻ |

**Options:**

| Option | Description |
|---|---|
| `-o`, `--output` | Output directory (default: `<bias_folder>/rtn_fits_output/`) |
| `--frames N` | Number of bias frames to use (default: all available) |
| `--lut PATH` | Path to threshold LUT file (default: `rts_threshold_lut.pkl`) |
| `--plot` | Display diagnostic plots interactively as the script runs |
| `--save-plots` | Save diagnostic plots to the output directory |
| `-v`, `--verbose` | Print progress per column during fitting |

**Example with sample data:**

```bash
python rtn_fitter.py "Sample Data/bias_cutouts" 3.26 --plot --save-plots -v
```

**Outputs** (written to the output directory):

| File | Description |
|---|---|
| `rtn_params.fits` | 6-layer FITS file containing fitted RTN parameters for each pixel: mean (e⁻), central peak fraction, low-state fraction, delta_x (e⁻), sigma (e⁻), and lambda_max (e⁻/pix/frame) |
| `mean_bias_frame.fits` | Mean of the bias stack |
| `read_noise_frame.fits` | Per-pixel read noise map (e⁻) |
| `read_noise_histogram.png` | Histogram of per-pixel read noise (if `--save-plots`) |
| `nonnormal_pixels.png` | Read noise distribution of pixels failing the Anderson-Darling normality test (if `--save-plots`) |
| `lambda_max_histogram.png` | Distribution of maximum correctable flux per RTN pixel (if `--save-plots`) |
| `snr_improvement.csv` | SNR improvement factor vs. flux (if `--save-plots`) |
| `snr_improvement.png` | Plot of SNR improvement vs. flux (if `--save-plots`) |
| `eff_read_noise.png` | Effective read noise vs. flux after correction (if `--save-plots`) |

### Step 2: Correct Science Frames (`rtn_fixer.py`)

Applies RTN correction to science frames using parameters from Step 1. A reference image is constructed for each frame (either via rolling temporal median or spatial median filter), and pixels that have jumped relative to this reference in a manner consistent with RTN are corrected.

```
python rtn_fixer.py <params_folder> <input_folder> <gain> [options]
```

**Arguments:**

| Argument | Description |
|---|---|
| `params_folder` | Path to folder containing `rtn_params.fits`, `mean_bias_frame.fits`, and `read_noise_frame.fits` (the output directory from `rtn_fitter.py`) |
| `input_folder` | Folder containing science FITS frames to correct |
| `gain` | Sensor gain in ADU/e⁻ |

**Options (must specify exactly one reference method):**

| Option | Description |
|---|---|
| `-w`, `--window N` | Use a rolling temporal median of N frames as the reference. Frames within N/2 of the edges are copied uncorrected. N should be at least 10. |
| `-m`, `--median-size N` | Use a spatial median filter of kernel size N as the reference. |

**Other options:**

| Option | Description |
|---|---|
| `-o`, `--output` | Output folder for corrected frames (default: `./corrected/`) |
| `-v`, `--verbose` | Print per-frame progress |

**Example with sample data (rolling temporal median):**

```bash
python rtn_fixer.py "Sample Data/bias_cutouts/rtn_fits_output" "Sample Data/science_cutouts" 3.26 -w 10 -o "Sample Data/corrected_science_cutouts/" -v
```

**Example with spatial median filter:**

```bash
python rtn_fixer.py "Sample Data/bias_cutouts/rtn_fits_output" "Sample Data/science_cutouts" 3.26 -m 5 -o "Sample Data/corrected_science_cutouts/" -v
```

**Outputs:**

| File/Folder | Description |
|---|---|
| `<output>/*.fits` | Corrected science frames (int16), with FITS header keywords `RTNCORR`, `RTNREF`, and `RTNWIN` or `RTNMEDSZ` recording the correction metadata |
| `<output>/updated_bias_frame/updated_bias_frame.fits` | Updated mean bias frame accounting for the net effect of RTN corrections applied |

**Reference method guidance:**

- **Rolling temporal median (`-w`)**: Best when you have a sequence of many frames of the same field or when the field is not oversampled. Edge frames (within half the window of the start/end) are copied without correction.
- **Spatial median filter (`-m`)**: Works on individual frames without requiring a time series. Should only be used if the PSF is oversampled by a fair degree.
